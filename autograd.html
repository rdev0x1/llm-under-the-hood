2.1 — Why Autograd exists

In Chapter 1 we differentiated tiny expressions by hand. A neural network contains millions or billions of parameters and thousands of chained operations. Doing this manually is impossible.

Forward pass

Compute actual numeric values from inputs and parameters until we obtain a loss.

Graph recording

Remember which values produced which later values.

Backward pass

Starting from the loss, apply each operation's local derivative rule in reverse.

Result

Every parameter receives dL/dparameter: its gradient.

The connection to Chapter 1

Autograd is essentially the chain rule plus bookkeeping.

2.3 — Local derivatives are enough

An operation does not need to understand the entire neural network. It only needs to know its own derivative.

Addition
c = a + b
∂c/∂a = 1
∂c/∂b = 1
Multiplication
c = a*b
∂c/∂a = b
∂c/∂b = a
Square
c = a²
∂c/∂a = 2a
Exponential
c = exp(a)
∂c/∂a = exp(a)
Chain rule as message passing

Each node receives an upstream gradient, multiplies it by its local derivative, and sends the result to its parents.

2.4 — The Value object

We now turn a plain number into a number that remembers enough information for automatic differentiation.

class Value:
    def __init__(self, data, children=(), op=""):
        self.data = data
        self.grad = 0.0
        self._prev = set(children)
        self._op = op
        self._backward = lambda: None
data

The ordinary numeric value computed during the forward pass.

grad

Eventually stores dL/dthis_value.

_prev

The values that were used to create this value: graph edges.

_backward

A tiny function containing this operation's local derivative rule.

Now addition can create both the output value and its backward rule:

def __add__(self, other):
    other = other if isinstance(other, Value) else Value(other)
    out = Value(self.data + other.data, (self, other), "+")

    def _backward():
        self.grad  += 1.0 * out.grad
        other.grad += 1.0 * out.grad

    out._backward = _backward
    return out
Forward and backward are paired.

The forward rule says how to compute out.data. The backward rule says how an upstream out.grad contributes to the parents.

2.5 — Why gradients must accumulate

A value can influence the loss through more than one path. The total derivative is the sum of all path contributions. That is why backward rules use +=, not =.

Shared-value example: y = x*x + x
x = 3 → dy/dx = 3 + 3 + 1 = 7
# Three paths from x to y:
# x → left input of multiplication   contributes x
# x → right input of multiplication  contributes x
# x → direct addition                contributes 1

x.grad += contribution_1
x.grad += contribution_2
x.grad += contribution_3
This is not an implementation detail.

Gradient accumulation is the multivariable chain rule applied to a graph with branches and merges.

2.6 — Why backward runs in reverse topological order

A node can only send its correct gradient backward after it has received all gradient contributions from nodes that depend on it.

forward order:
x, y → a = x*y → L = a+z

backward order:
L → a → x, y
  → z

A topological sort gives an ordering in which every parent appears before the child that depends on it. We then traverse that ordering in reverse.

topo = []
visited = set()

def build(node):
    if node not in visited:
        visited.add(node)
        for parent in node._prev:
            build(parent)
        topo.append(node)

build(loss)

loss.grad = 1.0
for node in reversed(topo):
    node._backward()
Why start with loss.grad = 1?

Because dL/dL = 1. That single 1 is the seed from which the entire backward pass grows.

2.7 — A minimal scalar Autograd engine

Put the pieces together and the core engine is surprisingly small. This is the conceptual ancestor of what PyTorch Autograd does at much larger scale.

class Value:
    def __init__(self, data, children=(), op=""):
        self.data = float(data)
        self.grad = 0.0
        self._prev = set(children)
        self._op = op
        self._backward = lambda: None

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), "+")

        def _backward():
            self.grad += out.grad
            other.grad += out.grad

        out._backward = _backward
        return out

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), "*")

        def _backward():
            self.grad += other.data * out.grad
            other.grad += self.data * out.grad

        out._backward = _backward
        return out

    def backward(self):
        topo = []
        visited = set()

        def build(node):
            if node not in visited:
                visited.add(node)
                for parent in node._prev:
                    build(parent)
                topo.append(node)

        build(self)
        self.grad = 1.0

        for node in reversed(topo):
            node._backward()
x = Value(2)
y = Value(3)
z = Value(4)

a = x * y
loss = a + z
loss.backward()

print(loss.data) # 10
print(x.grad)    # 3
print(y.grad)    # 2
print(z.grad)    # 1
