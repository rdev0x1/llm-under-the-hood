The building blocks before the Transformer

1.1 — Tensor & shape

A tensor is simply an array of numbers with any number of dimensions. A shape tells us how many elements exist along each axis.

Scalar5
shape []
Vector[2, 5, 7]
shape [3]
Matrix2 × 3
shape [2,3]
3D tensor32 × 128 × 768
shape [32,128,768]
LLM interpretation 
X.shape = [32, 128, 768]

32  = sequences in the batch
128 = tokens per sequence
768 = numbers representing each token

1.3 — Axes & sum(axis)

An axis is one dimension of a tensor. A reduction such as sum(axis=1) adds values along that axis and removes that dimension.

Before
[32,128,768]
sum(axis=1)
sum across the 128 tokens
After
[32,768]
X =
[[1, 2, 3],
 [4, 5, 6]]

sum(axis=0) → [5, 7, 9]
sum(axis=1) → [6, 15]

1.4 — Broadcasting

Broadcasting lets a smaller tensor participate in an operation with a larger tensor when their shapes are compatible. Shapes are aligned from the right; a dimension of size 1 can be expanded implicitly.

X : [32, 128, 768]
b :           [768]

X + b → [32, 128, 768]
Concrete example 
X =
[[1, 2, 3],
 [4, 5, 6]]

b = [10, 20, 30]

X + b =
[[11, 22, 33],
 [14, 25, 36]]

1.5 — Why this appears everywhere in an LLM

A linear layer transforms every token representation with the same weight matrix. This pattern appears constantly inside a transformer.

X.shape = [B, T, C]
W.shape = [C, D]
b.shape = [D]

Y = X @ W + b

Y.shape = [B, T, D]

Later, the Q, K, and V projections used by attention are built from exactly this kind of operation.
